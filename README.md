# ヘブライ語聖書 — 日本語版

ヘブライ語聖書(タナハ)の、原文の文字に忠実な逐節翻訳。

## ヘブライ語がまず先に

この訳は、あなたをヘブライ語へ近づけるために存在します。置き換える
ためではありません。読まれるべきものは常にヘブライ語 — その子音、
母音記号、アクセント — であり、その下の日本語は窓であって代用品では
ありません。両者が食い違って見えるとき、正しいのはヘブライ語です。

## 御名

四文字の神の名が現れる箇所では、**ヤハウェ** と書きます — 子音を
そのまま音写し、称号や別の形で置き換えません。御名はすべての箇所で
名のままです。ページのどこに御名が立つのか、常に分かるように。

## アレフ・タウ — ⟨את⟩

日本語の中に **⟨את⟩** が保持されているのに気づくでしょう。ヘブライ
語の אֵת は定まった目的語を標示する小さな語 — 行為の向かう先を指し
示す語 — で、日本語に相当語がありません。多くの翻訳は黙って省き
ます。私たちは山括弧に入れて見えるままにします。それは文の構造の
一部だからです。消すのではなく、そこにあることをお見せします。

## ⟨山括弧⟩の中の語

山括弧⟨このような⟩は、**ヘブライ語にはない**が日本語が文として
立つために必要な語 — 繋辞、助詞、接続 — を標示します。見えない形で
溶かし込む代わりに括弧に入れ、ヘブライ語固有の語と日本語が要求する
語とが常に区別できるようにします。

## 名と称号

ヘブライ語が神について固有の語を用いる箇所 — **エロヒム**、
**エル**、**シャッダイ**、**アドナイ** — は、すべて「神」に均して
しまわず、そのまま保持します。それぞれに固有の重みがあり、保持する
ことで本文が実際にどの語を用いたかが見えます。

## 各節をその場の光で

各節は、その場所で語ることをそのまま訳します — ヘブライ語の厳格な
唯一神信仰で読み、後代の教義を持ち込まず、物語の結末をその始まりに
読み戻しません。語をして、あるところで、意味することを意味させる。

## 本文の形

一節一ファイル:節そのものと、ヘブライ語に整列した逐語訳。各ヘブラ
イ語がその日本語の対応語と向かい合って読めるように。
